When an agent attempts an action governed by a `REQUIRE_APPROVAL` policy, Sericin creates an approval request and pauses the action until a designated approver responds. The Approvals API lets you build custom review interfaces, integrate approvals into your existing workflows, and pull approval history for audit and reporting purposes.

## List Approvals

Retrieve a list of approval requests, optionally filtered by status.

**Method:** `GET`
**URL:** `https://api.sericin.io/v1/approvals`

<CodeGroup>

```bash cURL
curl "https://api.sericin.io/v1/approvals?status=pending" \
  -H "Authorization: Bearer $SERICIN_API_KEY"
```

```python Python
import requests
import os

response = requests.get(
    "https://api.sericin.io/v1/approvals",
    headers={"Authorization": f"Bearer {os.environ['SERICIN_API_KEY']}"},
    params={"status": "pending"},
)

print(response.json())
```

```javascript Node.js
const response = await fetch(
  "https://api.sericin.io/v1/approvals?status=pending",
  {
    headers: {
      Authorization: `Bearer ${process.env.SERICIN_API_KEY}`,
    },
  }
);

const data = await response.json();
console.log(data);
```

</CodeGroup>

### Query Parameters

<ParamField query="status" type="string">
  Filter by approval status. Accepted values: `pending`, `approved`, or `rejected`. Omit to return requests in all states.
</ParamField>

## Approve a Request

Approve a pending approval request, allowing the paused agent action to proceed. Returns `200 OK` with the updated approval object.

**Method:** `POST`
**URL:** `https://api.sericin.io/v1/approvals/{id}/approve`

<CodeGroup>

```bash cURL
curl -X POST https://api.sericin.io/v1/approvals/apr_7x8y9z0a1b2c3d4e/approve \
  -H "Authorization: Bearer $SERICIN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "comment": "Reviewed and approved — vendor is on the approved list."
  }'
```

```python Python
import requests
import os

response = requests.post(
    "https://api.sericin.io/v1/approvals/apr_7x8y9z0a1b2c3d4e/approve",
    headers={
        "Authorization": f"Bearer {os.environ['SERICIN_API_KEY']}",
        "Content-Type": "application/json",
    },
    json={"comment": "Reviewed and approved — vendor is on the approved list."},
)

print(response.json())
```

```javascript Node.js
const response = await fetch(
  "https://api.sericin.io/v1/approvals/apr_7x8y9z0a1b2c3d4e/approve",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.SERICIN_API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      comment: "Reviewed and approved — vendor is on the approved list.",
    }),
  }
);

const approval = await response.json();
console.log(approval);
```

</CodeGroup>

### Request Body

<ParamField body="comment" type="string">
  An optional note explaining your approval decision. Recorded in the approval object and visible in audit logs.
</ParamField>

## Reject a Request

Reject a pending approval request, blocking the agent action. Returns `200 OK` with the updated approval object.

**Method:** `POST`
**URL:** `https://api.sericin.io/v1/approvals/{id}/reject`

<CodeGroup>

```bash cURL
curl -X POST https://api.sericin.io/v1/approvals/apr_7x8y9z0a1b2c3d4e/reject \
  -H "Authorization: Bearer $SERICIN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "comment": "Rejected — transfer amount exceeds weekly limit. Escalate to CFO."
  }'
```

```python Python
import requests
import os

response = requests.post(
    "https://api.sericin.io/v1/approvals/apr_7x8y9z0a1b2c3d4e/reject",
    headers={
        "Authorization": f"Bearer {os.environ['SERICIN_API_KEY']}",
        "Content-Type": "application/json",
    },
    json={"comment": "Rejected — transfer amount exceeds weekly limit. Escalate to CFO."},
)

print(response.json())
```

```javascript Node.js
const response = await fetch(
  "https://api.sericin.io/v1/approvals/apr_7x8y9z0a1b2c3d4e/reject",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.SERICIN_API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      comment: "Rejected — transfer amount exceeds weekly limit. Escalate to CFO.",
    }),
  }
);

const approval = await response.json();
console.log(approval);
```

</CodeGroup>

### Request Body

<ParamField body="comment" type="string" required>
  A note explaining your rejection decision. Required for reject requests. Recorded in the approval object and visible to the agent's operators in audit logs.
</ParamField>

## Get an Approval

Retrieve the full record for a single approval request by its ID. Returns `200 OK` with the approval object.

**Method:** `GET`
**URL:** `https://api.sericin.io/v1/approvals/{id}`

```bash
curl https://api.sericin.io/v1/approvals/apr_7x8y9z0a1b2c3d4e \
  -H "Authorization: Bearer $SERICIN_API_KEY"
```

## Approval Object Fields

<ResponseField name="id" type="string">
  The approval request's unique identifier, prefixed with `apr_`.
</ResponseField>

<ResponseField name="agent_id" type="string">
  The ID of the agent that triggered the approval request.
</ResponseField>

<ResponseField name="pipeline_run_id" type="string">
  The ID of the pipeline run in which the action was attempted. Returns `null` if the action was triggered outside a pipeline.
</ResponseField>

<ResponseField name="action" type="string">
  The name of the action the agent attempted that triggered the approval requirement.
</ResponseField>

<ResponseField name="policy_id" type="string">
  The ID of the policy that required approval for this action.
</ResponseField>

<ResponseField name="approver_group" type="string">
  The identifier of the team or role group designated to review this request.
</ResponseField>

<ResponseField name="requested_at" type="string">
  ISO 8601 UTC timestamp of when the approval request was created.
</ResponseField>

<ResponseField name="resolved_at" type="string">
  ISO 8601 UTC timestamp of when the request was approved or rejected. Returns `null` while status is `pending`.
</ResponseField>

<ResponseField name="status" type="string">
  Current status of the approval request. One of `pending`, `approved`, or `rejected`.
</ResponseField>

<ResponseField name="resolved_by" type="string">
  The user ID of the person who approved or rejected the request. Returns `null` while status is `pending`.
</ResponseField>

<ResponseField name="comment" type="string">
  The comment left by the reviewer when approving or rejecting. Returns `null` if no comment was provided.
</ResponseField>
